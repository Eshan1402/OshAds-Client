# Social calendar

1. Read `get_client_brief`, `get_posting_guide` and `list_social_queue` (to avoid duplicates).
2. Plan the requested period (default 2 weeks): at most one post per platform per day, inside the recommended windows, mixing formats — benefit spotlight, how-to, reward announcement, store-rating social proof, audience question.
3. Write each post within the platform's caption limit and hashtag guidance, ending with a CTA to the app's OshAds page. Only use facts from the brief.
4. Save with `save_social_drafts`, each with a one-line rationale.
5. Summarise what was drafted and remind the user that a person approves with `npm run social:review` before anything is published.

Never say a post has been published.
