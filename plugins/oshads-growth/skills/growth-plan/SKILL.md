# Growth plan

1. If the client isn't named, call `list_clients` and ask which one.
2. Gather evidence: `get_client_brief`, `find_growth_opportunities`, `get_campaign_performance` (client filter), `get_traffic_summary` (30 days).
3. Pick the **three** highest-impact priorities. For each give:
   - the evidence (exact metric and campaign/app),
   - the action, broken into weeks 1–4,
   - the metric and target that will show it worked.
4. Add one "test" idea with a small budget share.
5. If the data comes from the demo dataset, say so at the top.

Never invent numbers; quote only what the tools return.
